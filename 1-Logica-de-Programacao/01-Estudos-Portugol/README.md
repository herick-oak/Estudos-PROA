# 📘 01-Estudos-Portugol

Repositório com meus exercícios e projetos de estudo de algoritmos desenvolvidos em **Portugol**, como parte da disciplina de **Lógica de Programação**.

---

## 📌 Sobre o projeto

Este repositório contém meus estudos iniciais de lógica de programação utilizando o Portugol como ferramenta de aprendizado. O objetivo é compreender os fundamentos da programação antes de avançar para linguagens mais complexas.

Todos os exercícios presentes aqui foram passados pelo meu professor, com o propósito de desenvolver e aprimorar minha lógica na construção de algoritmos.

## 📚 Conteúdo dos exercícios

### 📁 01-Primeiro-Exercicio
Estudos iniciais de lógica de programação utilizando Portugol como ferramenta de aprendizado. O objetivo é compreender os fundamentos da programação antes de avançar para linguagens mais complexas.

### 📁 02-Segundo-Exercicio
Prática de estruturas condicionais em Portugol. Exercícios focados em **SE**, **SENÃO** e **SENÃO SE** para criar fluxos de decisão e tornar os algoritmos mais dinâmicos através de problemas práticos do dia a dia.

### 📁 03-Terceiro-Exercicio
Exploração de laços de repetição em Portugol. Exercícios com **ENQUANTO**, para automatizar tarefas repetitivas e desenvolver algoritmos mais eficientes e otimizados.

### 📁 05-Quinto-Exercicio
Simulador de caixa eletrônico desenvolvido em Portugol como prática de lógica de programação. O projeto implementa operações bancárias (saldo, extrato, saque, depósito e transferência) com validações de segurança, uso de estruturas de decisão (**ESCOLHA/CASO**) e tratamento de erros, aplicando melhorias em um código base fornecido pelo professor.

## 🛠️ Ferramentas utilizadas

- **[Portugol Studio](https://univali-lite.github.io/Portugol-Studio/)** — ambiente de desenvolvimento utilizado para escrever e executar os algoritmos.

---

## ▶️ Como executar os exercícios

1. Instale o **Portugol Studio**;
2. Clone este repositório: `git clone <url-do-seu-repositorio>`;
3. Entre na pasta do exercício desejado;
4. Abra o arquivo `.por` no Portugol Studio;
5. Clique em **Executar** e veja o algoritmo rodar.
