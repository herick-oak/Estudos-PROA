# 📘 02-Estudos-Kotlin

Repositório com meus exercícios e projetos de estudo de algoritmos desenvolvidos em **Kotlin**, como parte da disciplina de **Lógica de Programação**.

---

## 📌 Sobre o projeto

Este repositório reúne meus estudos iniciais de lógica de programação, utilizando a linguagem **Kotlin** como principal ferramenta ao longo do curso. O objetivo é consolidar os fundamentos da programação antes de avançar para conceitos mais complexos.

Todos os exercícios presentes aqui foram passados pelo meu professor, com o propósito de desenvolver e aprimorar minha lógica na construção de algoritmos.

## 📚 Conteúdo dos exercícios

### 📁 01-Primeiro-Exercicio
Estudos iniciais de lógica de programação utilizando a linguagem Kotlin como principal ferramenta ao longo do curso. O objetivo é consolidar os fundamentos da programação antes de avançar para conceitos mais complexos.

### 📁 02-Segundo-Exercicio
Prática de estruturas condicionais em Kotlin. Exercícios focados em **IF**, **ELSE IF**, **ELSE** e **WHEN** para criar fluxos de decisão e tornar os algoritmos mais dinâmicos através de problemas práticos do dia a dia.

### 📁 03-Terceiro-Exercicio
Exploração de laços de repetição em Kotlin. Exercícios com **While** e **For**, para automatizar tarefas repetitivas e desenvolver algoritmos mais eficientes e otimizados.

### 📁 04-Quarto-Exercicio
Explorando Arrays e Coleções em Kotlin. Exercícios com **List** e **MutableList**, abordando a criação de listas, busca de elementos com o operador `in` e funções como `find` e `remove`, além da manipulação dinâmica de coleções (adicionar e remover itens). Tudo aplicado em problemas práticos como cadastro de estudantes, verificação de planetas e gestão de uma lista de compras.

### 📁 05-Quinto-Exercicio
Simulador de caixa eletrônico desenvolvido em Kotlin como prática de lógica de programação. O projeto implementa operações bancárias (saldo, extrato, saque, depósito e transferência) com validações de segurança, uso de estruturas de decisão (**WHEN**) e tratamento de erros, aplicando melhorias em um código base fornecido pelo professor.

### 📁 07-Setimo-Exercicio
Projeto de estudo em Kotlin que simula a gestão de um hotel via terminal. Inclui reservas de quartos, cadastro de hóspedes, eventos, orçamentos e relatórios operacionais. Desenvolvido com foco em modularização, validação de dados e prática de lógica de programação. Não possui persistência de dados.

### 📁 08-Oitavo-Exercicio
Estudo sobre a utilização da Programação Orientada a Objetos (POO), abordando conceitos fundamentais como **classes**, **atributos** e **métodos**, e destacando sua importância no desenvolvimento de software moderno.

## 🛠️ Ferramentas utilizadas

- **[Kotlin](https://kotlinlang.org/)** — linguagem moderna, concisa e segura utilizada em todo o projeto.
- **[IntelliJ IDEA](https://www.jetbrains.com/idea/)** — ambiente de desenvolvimento (IDE) utilizado para escrever e executar os códigos.

---

## ▶️ Como executar os exercícios

1. Instale o **IntelliJ IDEA** (Community Edition) ou configure o Kotlin no seu editor preferido;
2. Clone este repositório: `git clone <url-do-seu-repositorio>`;
3. Abra o projeto no IntelliJ IDEA;
4. Navegue até a pasta do exercício desejado;
5. Abra o arquivo `.kt` e clique no ícone ▶️ ao lado da função `main()` para executar.
