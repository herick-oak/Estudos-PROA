# 🧠 Logica de Programacao

Repositório central dos meus estudos na disciplina de **Lógica de Programação** do curso **PROA**. Aqui está registrada toda a minha jornada de aprendizado: dos fundamentos em pseudocódigo (Portugol) até a prática em uma linguagem real de mercado (Kotlin).

---

## 📌 Sobre o projeto

Este espaço reúne todos os meus exercícios e projetos da disciplina de Lógica de Programação. O caminho de aprendizado foi organizado em duas etapas complementares:

1. **Portugol** — primeiro contato com os fundamentos da programação em pseudocódigo, focando em entender a lógica sem se preocupar com sintaxes complexas;
2. **Kotlin** — aplicação e consolidação dos mesmos conceitos em uma linguagem real, moderna e utilizada pelo mercado.

Todos os exercícios foram passados pelo meu professor, com o propósito de desenvolver e aprimorar minha lógica na construção de algoritmos.

## 📚 Jornada de aprendizado

### 🥇 Etapa 1 — Portugol (pseudocódigo)
- Fundamentos da lógica de programação;
- Estruturas condicionais (**SE**, **SENÃO**, **SENÃO SE**);
- Laços de repetição (**ENQUANTO**);
- Simulador de caixa eletrônico com **ESCOLHA/CASO**.

### 🥈 Etapa 2 — Kotlin (linguagem real)
- Sintaxe e fundamentos da linguagem;
- Estruturas condicionais (**IF**, **ELSE IF**, **ELSE**, **WHEN**);
- Laços de repetição (**While**, **For**);
- Arrays e coleções (**List**, **MutableList**);
- Simulador de caixa eletrônico (versão evoluída);
- Sistema de gestão de hotel via terminal;
- Programação Orientada a Objetos (classes, atributos e métodos).

---

## 🔄 De Portugol a Kotlin

Uma das partes mais interessantes dessa jornada é ver como os mesmos conceitos se traduzem entre as linguagens:

| Conceito | Portugol | Kotlin |
| --- | --- | --- |
| Condicional | `SE` / `SENAO` | `if` / `else` |
| Condição múltipla | `SENAO SE` | `else if` |
| Escolha múltipla | `ESCOLHA` / `CASO` | `when` |
| Laço de repetição | `ENQUANTO` | `while` |
| Laço contado | `PARA` | `for` |
| Listas | `vetor` | `List` / `MutableList` |
| Entrada de dados | `leia()` | `readln()` |
| Saída de dados | `escreva()` | `println()` |
